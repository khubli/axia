# My Axia

My private settings and memory for [Axia](https://github.com/khubli/axia).
Keep this repository **private**: it holds my resume, the companies I'm
watching and how every role scored against me.

| File | What it is |
|---|---|
| `cv.md` | My resume, in Markdown |
| `criteria.md` | What a good role looks like for me, in my words |
| `companies.yml` | The companies to watch |
| `levels.md` | Optional: my level, and what it is called at the companies I watch |
| `pay.yml` | Optional: pay figures I know of, by employer and level |
| `settings.yml` | Titles, places, scoring, messages and the dashboard address |
| `calibration/` | Optional: roles I judged myself, to check the scorer |
| `moonshots.json`, `tailored.json` | Optional: written by my own tools, for the Moonshots tab and Tailor requests |
| `data/jobs.json` | Written by Axia: every matching role and its score |
| `data/feedback.json` | Written by Axia: my calls on the dashboard, with each posting |
| `dashboard/README.md` | Written by Axia: the plain list, readable on GitHub |
| `.github/workflows/axia.yml` | Runs Axia every morning |

Setup: https://github.com/khubli/axia/blob/main/docs/setup.md
